# Phrasing — cycle-count-execution

- Tolerances phrased as: "2% by value for A-items, 5% for B and C items".
- ABC schedule phrased as: "A-items monthly, B-items quarterly, C-items annually".
- "blind" count sheets: lowercase, glossed as "location and item but not the system (book) quantity".
- Recount sheets: "marked RECOUNT in red" (RECOUNT in caps).
- The paper log handed to the Plant Controller is "the adjustment log".
- Timing phrased as "the next business day" (not "next morning").
