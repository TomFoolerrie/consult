# Screenshot Placeholder Rules

Do not insert screenshots. Create labeled placeholders only.

Use screenshot IDs: `SC-01`, `SC-02`, etc.

Add body placeholders using:

```markdown
> **SCREENSHOT PLACEHOLDER — SC-01:** [Caption]. User to insert screenshot showing [specific screen/report/action].
```

Populate Appendix D | Screenshot / Evidence Index with:

- SC ID
- Caption
- Procedure / Step
- Source
- Why Needed
- Status = `Pending user input`
- Owner = `TBD`, unless known
- Archive Location = `TBD`, unless known

Recommend screenshots only when they:

- Reduce execution risk
- Clarify navigation
- Evidence a control
- Document a key output
- Prevent ambiguity in user execution
