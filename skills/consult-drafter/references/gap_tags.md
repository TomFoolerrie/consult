# Gap Tags

Use these tags to mark uncertainty in the body of the SOP. Every material tag must be logged in Appendix C | Gap / Validation Log.

## General

- `[[GAP — NOT DOCUMENTED]]`
- `[[UNCONFIRMED — VALIDATE]]`
- `[CONFIRM]`

## Ownership / Responsibility

- `[[GAP — OWNER UNKNOWN]]`
- `[[GAP — REVIEWER UNKNOWN]]`
- `[[GAP — APPROVER UNKNOWN]]`

## Process Mechanics

- `[[GAP — SYSTEM UNKNOWN]]`
- `[[GAP — TIMING UNKNOWN]]`
- `[[GAP — FREQUENCY UNKNOWN]]`
- `[[GAP — INPUT UNKNOWN]]`
- `[[GAP — OUTPUT UNKNOWN]]`
- `[[GAP — NAVIGATION PATH UNKNOWN]]`
- `[[GAP — FIELD / PARAMETER UNKNOWN]]`

## Controls / Evidence

- `[[GAP — CONTROL NOT EVIDENCED]]`
- `[[GAP — APPROVAL NOT EVIDENCED]]`
- `[[GAP — EVIDENCE RETENTION UNKNOWN]]`
- `[[GAP — ARCHIVE LOCATION UNKNOWN]]`

## Exceptions / Dependencies

- `[[GAP — EXCEPTION HANDLING UNKNOWN]]`
- `[[GAP — DOWNSTREAM DEPENDENCY UNKNOWN]]`
- `[[GAP — UPSTREAM DEPENDENCY UNKNOWN]]`
