# Evidence Rules

## Standard

Use balanced evidence discipline. Add obvious connective tissue, but do not invent procedural facts.

## Allowed Without Explicit Source Quote

- Neutral transitions
- Minor grammar and sequencing cleanup
- Role-name normalization
- Combining duplicate statements
- Headings and labels required by the template

## Must Be Supported or Flagged

- Systems and tools
- Navigation paths
- Field names
- Frequencies and timing
- Owners, reviewers, approvers
- Inputs and outputs
- Controls and evidence
- Exception handling
- Archive / retention locations
- Downstream dependencies
- Approval thresholds

## Conflicts

If sources conflict, do not choose silently. State the conflict and log a gap.
